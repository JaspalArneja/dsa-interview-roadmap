## ⚡ Quick Input Size (`N`) → Target Time Complexity Cheat Sheet

| Max Input Size (`N`) | Target Time Complexity | Go-To Algorithmic Patterns |
| :--- | :--- | :--- |
| `N ≤ 10..12` | `O(N!)` or `O(2^N)` | Backtracking: Permutations, N-Queens |
| `N ≤ 20` | `O(2^N)` or `O(N · 2^N)` | Recursion Subsets, Bitmask DP |
| `N ≤ 500` | `O(N³)` | Floyd-Warshall, Interval DP |
| `N ≤ 2,000..5,000` | `O(N²)` | 2D DP (LCS, Edit Distance), 3Sum |
| `N ≤ 10⁵` | `O(N log N)` or `O(N)` | Sorting, Heap, Binary Search, Two Pointers, Sliding Window, Hash Map |
| `N ≤ 10⁹` | `O(log N)` or `O(1)` | Binary Search on Answer, Bit Manipulation, Math |
